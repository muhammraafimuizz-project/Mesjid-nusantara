# Donasi Simulasi via n8n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Setiap donasi simulasi dari halaman Donasi tersimpan sebagai satu baris di Google Sheets dan memicu notifikasi Telegram ke admin, semuanya lewat satu webhook n8n.

**Architecture:** Form di `/donasi` memanggil satu server function TanStack Start. Server function memvalidasi input, membuat kode donasi, lalu POST ke webhook n8n. n8n menambah baris di Google Sheets lalu mengirim pesan Telegram. URL dan secret webhook hanya ada di server (env). Tidak ada dependency baru dan tidak ada pembayaran nyata.

**Tech Stack:** TanStack Start (React + TS), Vitest, n8n, Google Sheets, Telegram Bot, Bun.

**Spec:** Permintaan pengguna di chat (1 Nov 2026): donasi masuk ke spreadsheet, admin diberi notifikasi Telegram lewat n8n, donasi hanya simulasi.

## Global Constraints

- Package manager: Bun. Test runner: Vitest (`bun run test`).
- Jangan edit `src/routeTree.gen.ts` manual.
- Env server-only: `N8N_WEBHOOK_URL`, `N8N_WEBHOOK_SECRET`. Jangan pakai prefix `VITE_`.
- Secret dikirim lewat header `x-webhook-secret`; node Webhook n8n memakai Header Auth dengan nilai yang sama.
- Token bot Telegram hanya disimpan di Credentials n8n.
- Nominal: bilangan bulat Rupiah, minimum 10000, maksimum 1000000000.
- Status awal selalu `Menunggu`. Kode donasi dibuat di server: `DON-YYMMDD-XXXX` (tanggal Asia/Jakarta, XXXX = 4 karakter acak A-Z0-9).
- Halaman Donasi harus menampilkan label "Simulasi, tidak ada pembayaran nyata" dan tidak menampilkan nomor rekening asli.
- Pertahankan gaya desain yang ada.

## Review Focus

- Nama/pesan diawali `=`, `+`, `-`, `@` (formula injection di Sheets): dikirim dengan awalan `'` dan disimpan sebagai teks.
- Nominal 0, negatif, desimal, teks, atau di luar batas: ditolak dengan pesan jelas.
- Tombol kirim ditekan dua kali: hanya satu baris tercipta.
- n8n mati/timeout: pengunjung melihat pesan gagal, bukan "berhasil" palsu.
- Nama/pesan berisi karakter Markdown atau tautan: notifikasi Telegram dikirim sebagai teks biasa.
- Donatur memilih anonim: nama tetap tersimpan di sheet untuk admin, `anonim` = YA.
